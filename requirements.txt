# ── The NumPy pin is the load-bearing line ──────────────────────────────────
# TensorFlow 2.13 (Mask R-CNN) needs numpy ~1.24 (<1.25).
# The latest ultralytics (8.4.x) declares `numpy>=1.23.0` with NO upper cap.
#   → numpy 1.24.3 satisfies BOTH, so they coexist in ONE process.
# BUT: ultralytics has no upper bound, so a fresh `pip install` would pull
# numpy 2.x and BREAK TensorFlow. Keeping numpy==1.24.3 pinned in your main
# requirements.txt forces pip to keep 1.24.3 (it satisfies ultralytics' >=1.23.0).
# DO NOT let pip upgrade numpy. Verify after install:
#   python -c "import numpy;print(numpy.__version__)"  → must print 1.24.3

# CPU PyTorch — torch>=1.8 satisfies the latest ultralytics; 2.1.2 is numpy-1.24-safe.
